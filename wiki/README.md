# Forge Wiki

Long-form guides, research notes, and operational documentation that doesn't belong in code comments.

**What goes here:**
- Deep-dives on specific subsystems (e.g., "How the transcript scorer selects golden segments")
- Research notes on models, latency benchmarks, API behavior
- Operational runbooks longer than what fits in DEPLOYMENT.md
- Onboarding guides for new team members

**What does NOT go here:**
- Interface contracts → HANDOFF.md
- Environment setup → DEPLOYMENT.md
- Code patterns → subsystem CLAUDE.md files
- Architecture decisions → decisions/

**Format:** Markdown files, named `topic-name.md`. Link from here when you add one.
